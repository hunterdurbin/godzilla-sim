# comprehensive_rules/ — official game rules

`251223-v1.1-Godzilla-TCG-Comprehensive-Rules.pdf` — the official Godzilla
TCG comprehensive rules (v1.1, 2025-12-23). The `.gdignore` keeps Godot from
importing this directory.

Engine code cites rules by section number — e.g.
`scripts/effects/check_timing.gd` implements "rule 10.4.3" (standby
resolution ordering). When a comment says "per rule N.N.N", this PDF is the
source of truth.

`rules.txt` is a greppable text copy, generated by `extract_text.sh`
(needs `pdftotext`). Look a rule up by number with its trailing period:
`grep -A4 '^5\.11\.1\.1\.' comprehensive_rules/rules.txt`. The PDF stays
authoritative if the two ever disagree.

Quick orientation: 2 players, 8 zones + 2 strategy zones; win by invading
past zone 8, or when the opponent can't rank up while countered. Turn flow:
Start → Main → Counter → End. Threat = base + rage × 5000. Deck rules live in
`scripts/cards/deck_validator.gd` (50-card main deck, 4 monsters rank 1–4,
≤10 invade-2 cards, …).

## Japanese originals — `rules-ja.txt`, `qa-ja.txt`

The game is Japanese, so the English rules and rulings are translations.
When the English wording seems to split one act in two, or contradicts a
ruling, check the Japanese. Japanese card ids drop the `E` (`BP02-055` is
EBP02-055); the rule numbers are the same.

- `GodzillaTCG_cr_<ver>_<yymmdd>-ja.pdf` is the official Japanese
  comprehensive rules. `rules-ja.txt` is its greppable copy:
  `./extract_text.sh GodzillaTCG_cr_1.06_261102-ja.pdf rules-ja.txt`.
  Lines wrap mid-sentence (Japanese has no spaces), so use `grep -A4`.
- `qa-ja.txt` holds every Japanese ruling, in the same format as `qa.txt`.
  It comes from `https://godzilla-cardgame.com/manage/rule-qa/list?per_page=1000`
  with the recipe below, run on `https://godzilla-cardgame.com/question/`,
  with `(JA)` in the header and the file saved as `godzilla-qa-ja.txt`.
  It has more rulings than `qa.txt` because the English site lags.
- Japanese card text is at `/manage/card-list-user/detail/?card_number=BP02-055`
  on the same site (`card.text`).

**Play (出現).** The Japanese rules use one verb, 出現, for 5.11 "play",
5.11.4 "play a token", 9.1.2 "cause a token to appear" and 5.17.1 Evolve
("重ねて出現させます"). The cards use it too: EBP02-073 "出現するたび",
EBP04-028 / EBP04-072 "山札から…出現させるたび", EBP02-055
"出現させることができない". So the English "appear" is a play, and Evolve is a
play from the deck (Q176, Q270).

## Official Q&A — `qa.txt`

`qa.txt` holds every official English Q&A ruling, one block per ruling.
Rulings override the rules text where they disagree. Look one up by number
or card id:

```
grep -A2 '^Q480 ' comprehensive_rules/qa.txt
grep -A2 'EBP03-058' comprehensive_rules/qa.txt
```

Each block is `Q<n> (<date>) [<card id> : <name>] <category>`, then `Q:` and
`A:` lines. Card ids in the header use the same `EBP03-058` form as the card
set files.

**Refreshing it.** The source is
`https://en.godzilla-cardgame.com/manage/rule-qa/list?per_page=1000` (JSON:
`items[]` with `id` = Q number, `question`, `answer`, `update_time`,
`card_names`, `category_label`). It answers browsers only; curl and WebFetch
get a 404 or an empty JavaScript shell. Refresh through Claude in Chrome:

1. Open `https://en.godzilla-cardgame.com/question/` in a Chrome tab.
2. Run this in the page (DevTools console, or the extension's JavaScript tool);
   it downloads `godzilla-qa.txt`:

   ```js
   const j = await fetch('/manage/rule-qa/list?per_page=1000').then(r => r.json());
   const it = [...j.items].sort((a, b) => a.id - b.id);
   const clean = s => String(s || '').replace(/\r/g, '').replace(/\s*\n\s*/g, ' ').trim();
   const body = it.map(x => `Q${x.id} (${x.update_time}) ${x.card_names ? x.card_names + ' ' : ''}${x.category_label}\nQ: ${clean(x.question)}\nA: ${clean(x.answer)}\n`).join('\n');
   const header = `# Official Godzilla Card Game Q&A (EN), ${it.length} rulings, fetched ${new Date().toISOString().slice(0, 10)}\n# Source: https://en.godzilla-cardgame.com/manage/rule-qa/list?per_page=1000 — refresh recipe in comprehensive_rules/README.md\n\n`;
   const a = Object.assign(document.createElement('a'), {
     href: URL.createObjectURL(new Blob([header + body], {type: 'text/plain'})),
     download: 'godzilla-qa.txt',
   });
   document.body.appendChild(a); a.click(); a.remove();
   ```
3. `mv ~/Downloads/godzilla-qa.txt comprehensive_rules/qa.txt`. Check that
   `grep -c '^Q[0-9]' comprehensive_rules/qa.txt` matches the count in the header.

A single card's rulings are also at
`/manage/card-list-user/detail/?card_number=<id>` (`faqs[]`, with `qa_id`).

## New rules versions

When a new rules version releases, drop the new PDF here (keep the dated
filename scheme), run `extract_text.sh` to regenerate `rules.txt`, and
update this README.
